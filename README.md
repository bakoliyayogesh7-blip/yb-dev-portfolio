# YB Dev Portfolio

A responsive personal developer portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and metadata
- `styles.css` — layout, theme, responsive design, accessibility styles
- `script.js` — mobile menu, current year, copy-handle interaction
- `assets/favicon.svg` — site icon

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For a local server, use Python from this folder: `python -m http.server 8000`, then visit `http://localhost:8000`.

## Deploy
Upload the folder to a static host such as Netlify, GitHub Pages, or Cloudflare Pages. No build step is required.

## Personalize before publishing
- Confirm the display name (`YB Dev`) and social handle (`yb_dev`).
- Replace the generic LinkedIn URL with your actual profile URL.
- Add your GitHub profile only if you want it public.
- The FocusBlocker website link is set to `https://focusblockerapp.netlify.app/`.
- The portfolio deliberately does not claim that every feature is released or production-ready.

## Notes
- Google Fonts are loaded from Google Fonts; system font fallbacks remain available if offline.
- The contact section currently links to LinkedIn and copies the `yb_dev` handle. It does not collect or send messages.
